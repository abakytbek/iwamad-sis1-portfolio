# Side Notes - Personal Portfolio

https://abakytbek.github.io/iwamad-sis1-portfolio/

## About the Project

Side Notes is my personal portfolio website created for the iwamad SIS1 assignment.

It presents my web development skills and showcases practical assignments completed during the course.

The website serves as a starting point for my planned SIS2 blog that is named Side Notes.

## Design Decisions

### 1. Layout

I based the website structure on the HTML and CSS concepts covered during the course. I chose a simple, minimalistic single-page layout with About Me, Projects, and Contact sections to keep the website organized and easy to navigate.

### 2. Colors

I chose neutral colors with blue accents to create a clean and readable design. I also included light and dark themes to give visitors a choice of appearance.

### 3. Mobile Responsiveness

Responsive design was considered from the beginning as it was one of the assignment requirements. I used a two-column layout for project cards on desktop and a single-column layout on mobile to make the content more comfortable to read. During testing at 375px, I checked the card arrangement and spacing to make sure the layout worked well on smaller screens.
